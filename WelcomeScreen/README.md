COMPARING HEART DISEASE TRENDS BETWEEN MALES AND FEMALES

Description 
This project analyzes cardiovascular disease data from the CDC to compare
reported prevalence estimates between the females in the United States. 
The project examines changes overtime and compares several cardiovascular 
conditions, including heart attack, coronary heart disease, and heart failure.

Research Question
Are males and females affected differently by cardiovascular disease in the 
United States?

Dataset
The data comes from the CDC NHANES National Cardiovascular Disease Surveillance
System. It includes data from 1999-2000 through 2017-2018. The original dataset 
contains 5,122 rows and 30 columns.

Methods
- Load and clean the dataset
- Remove missing values
- Organize data by sex and survey year
- Calculate descriptive statistics 
- Compare male and female prevalence estimates 
- Create graphs using Matplotlib

Project Files
- script.py - Main analysis script

Data 
- nhanes_cardiovascular_data.csv - Original dataset

Results 
- cleaned_cardiovascular_data.csv - Cleaned dataset
- gender_comparisons.csv - Male and female comparisons
- descriptive_summary.csv - Descriptive statistics
- graph images showing cardiovascular disease trends

Tools used
- python
- pandas
- matplotlib
- pycharm

Conclusion
This project uses data analysis and visualizations to examine differences in
cardiovascular disease prevalence estimates between males and females 
over time.
